>_ ARCHIVO CLASIFICADO: INTRODUCCIÓN

Bienvenido al laboratorio. Entorno dedicado al análisis de la seguridad informática en la era de transición: el cifrado asimétrico moderno se sostiene sobre problemas matemáticos difíciles para una computadora clásica, pero potencialmente triviales para una computadora cuántica suficientemente grande.

>_ AMENAZA: EL ALGORITMO DE SHOR

Propuesto por Peter Shor en 1994, este algoritmo cuántico factoriza enteros grandes y resuelve logaritmos discretos en tiempo polinómico. En la práctica esto significa que rompería tanto RSA como ECC.

# Pseudocódigo conceptual del Algoritmo de Shor def shor(N): a = random_coprime(N) # elegir base aleatoria r = quantum_period_find(a, N) # QFT: hallar el período (paso cuántico) if r % 2 != 0: return retry() factor = gcd(a**(r//2) - 1, N) # reducción clásica return factor # clave privada comprometida
  • [!] Rompe RSA factorizando el módulo N
  • [!] Rompe ECC resolviendo el logaritmo discreto elíptico
  • [!] Requiere miles de qubits lógicos estables (aún no disponibles)

>_ DIAGRAMA_02: ARQUITECTURA DE UN PROCESADOR CUÁNTICO

>_ COMPUTACIÓN CUÁNTICA: EL RELOJ CORRE

El riesgo real no es solo futuro. Bajo el modelo "Harvest Now, Decrypt Later", un adversario puede capturar tráfico cifrado hoy y descifrarlo mañana, cuando exista una máquina cuántica capaz de ejecutar Shor a escala.

Por eso el NIST ya estandarizó algoritmos de Criptografía Post-Cuántica (PQC) resistentes a Shor, basados en retículos (lattices) en lugar de factorización o curvas elípticas.
